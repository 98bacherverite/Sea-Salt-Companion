name: Mid-game extension activation
description: Product decision for enabling an expansion during an active match.
---

The user wants an expansion to be addable during an active game.

**Why:** the user explicitly confirmed mid-game activation should be possible.

**How to apply:** record the change in the match history and apply it from the next round, preserving validated scores and each existing round's rule snapshot. Label mid-game activation as a house-rule option because the official rulebooks specify adding expansions during setup.
